# 01-需求文档（PRD）—— 企业级分级知识库

> 版本 v0.1 ｜ 2026-08-18 ｜ 状态：MVP 立项

## 1. 一句话定位

一个能落地的企业知识库：企业各部门数据集中入库，**按部门隔离、按密级分级**，员工可上传文档、检索定位文件、与 AI 对话获取答案；越权有明确拒绝，未命中有明确告知。

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 普通员工 | 上传本部门文档；查资料、问问题；只看得到本部门且密级够的数据 |
| 部门主管 | 管理本部门文档；查看本部门审计日志 |
| 老板/管理员 | 跨部门全局可见；全局审计 |

## 3. 权限模型（本项目灵魂）

**模型：RBAC + 密级（部门隔离 × 密级分级）**

- 文档两个标签：`所属部门`（可多选，支持跨部门联合文档）+ `密级`（1 普通 / 2 内部 / 3 机密）
- 人两个属性：`所属部门` + `密级`（员工=1、主管=2、老板=3）
- **可见规则**：部门匹配（或老板）AND 人密级 ≥ 文档密级
- **硬性工程规则**：权限过滤必须在**检索阶段**执行（查询时带部门+密级过滤条件），禁止"先检索后过滤结果"——防止员工从"有无命中"推断机密文档的存在（存在性泄露）

## 4. MVP 功能范围（只做这 5 个）

| # | 功能 | 验收要点 |
|---|---|---|
| F1 | 文档上传与解析 | 支持 PDF/Word/Excel/TXT；失败标记原因、可重试；**失败文档不进检索库** |
| F2 | 分级权限 | 部门+密级双层控制；权限实时生效（不缓存）；越权访问返回明确"权限不足" |
| F3 | 对话问答 | 混合检索（向量+关键词）；答案带引用溯源；未命中明确告知"未查到" |
| F4 | 检索定位文件 | 可只检索不生成，返回命中文档与切片位置 |
| F5 | 审计日志 | 记录上传/查询/越权尝试/权限变更；主管查本部门、老板查全部 |

**不做清单（v1 明确放弃）**：文档版本管理、审批流、在线编辑、评论协作、移动端、多租户 SaaS 化、GraphRAG/RAPTOR 增强、用户自助注册（账号由管理员预置）。

## 5. 业务规则

1. 脏数据不进库：解析失败的文档不产生任何可检索切片
2. 权限即改即生效：权限校验实时计算，不依赖缓存
3. 越权行为必留痕：所有越权访问尝试写入审计日志
4. 答案必须带引用；引用不到的内容必须拒答（幻觉控制）
5. 密钥只走 .env / 环境变量，永不入库入镜像

## 6. 边界与异常

| 情况 | 规则 |
|---|---|
| 解析失败 | 状态标记失败+原因，可重试，不进库 |
| 离职/调岗 | 权限实时校验，变更立即生效并记审计 |
| 跨部门文档 | 文档支持挂多个部门标签 |
| 大文件 | 单文件 ≤ 50MB，超限拒绝并提示 |

## 7. 成功标准（可量化，最终写进 README 评估报告）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 检索命中率 | top-3 ≥ 90% | 自造 20 条问答测试集 |
| 答案正确率 | ≥ 85% | 人工评估 / LLM 裁判 |
| **权限越权** | **0 泄露** | 10 个越权测试用例全过 |
| 幻觉控制 | 陷阱题 100% 拒答 | 问库中不存在的内容 |
| 响应时间 | 检索 < 2s | 本机实测 |
